▶ PLAY ON CHANGER — a Home Assistant webhook. When it's set, a ▶ PLAY ON CHANGER button appears in the disc view.

HOME ASSISTANT SET-UP (COPY AND ADAPT) 
automation:
  - alias: CrateChanger - play disc
    triggers:
      - trigger: webhook
        webhook_id: your-long-random-id
        allowed_methods: [POST]
        local_only: false   # needed when you reach Home Assistant through Nabu Casa
    conditions:
      - "{{ (trigger.json.event if trigger.json is defined else trigger.data.event) == 'play' }}"
    actions:
      - variables:
          slot: "{{ trigger.json.slot if trigger.json is defined else trigger.data.slot }}"
      # replace with whatever drives your changer (IR blaster, ESPHome, S-Link bridge ...)
      - action: remote.send_command
        target: { entity_id: remote.living_room }
        data: { device: cd_changer, command: "disc_{{ slot }}" }

# optional - lets this page see Home Assistant's answer ("SENT ✓"):
http:
  cors_allowed_origins:
    - https://rmillerpine75.github.io
Sent fields: event (play / test), slot, slot_padded, artist, album. Without the CORS line the play command still goes through — the page just can't confirm it.
