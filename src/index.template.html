☁ SYNC BETWEEN DEVICES — through a private GitHub Gist, using a GitHub token that can touch only your gists. CREATE THE TOKEN ↗ opens GitHub with everything pre-filled (Gists: read and write, nothing else, 1-year expiry) — click Generate token, copy it, paste it below. Once on each device.

The token stays in this browser only and is never put in backups or in the synced data. Every page on this address (…github.io) could read it, so don't host untrusted pages there.

🔎 SONG IDENTIFICATION — in the listening room, 🔎 IDENTIFY records about 8 seconds from the microphone and sends that clip to AudD, a music-recognition service, to find out what's playing — even if it isn't one of your CDs. (🎤 LISTEN on its own never sends audio anywhere.) Needs your own AudD API token: GET A TOKEN ↗ — the first 300 requests are free, then about $5 per 1,000. AUTO checks roughly once per song.

▶ PLAY ON CHANGER — a Home Assistant webhook. When it's set, a ▶ PLAY ON CHANGER button appears in the disc view.

HOME ASSISTANT SET-UP (COPY AND ADAPT) 
automation:
  - alias: CrateChanger - play disc
    triggers:
      - trigger: webhook
        webhook_id: your-long-random-id
        allowed_methods: [POST]
        local_only: false   # needed when you reach Home Assistant through Nabu Casa
    conditions:
      - "{{ (trigger.json.event if trigger.json is defined else trigger.data.event) == 'play' }}"
    actions:
      - variables:
          slot: "{{ trigger.json.slot if trigger.json is defined else trigger.data.slot }}"
      # replace with whatever drives your changer (IR blaster, ESPHome, S-Link bridge ...)
      - action: remote.send_command
        target: { entity_id: remote.living_room }
        data: { device: cd_changer, command: "disc_{{ slot }}" }

# optional - lets this page see Home Assistant's answer ("SENT ✓"):
http:
  cors_allowed_origins:
    - https://rmillerpine75.github.io
Sent fields: event (play / test), slot, slot_padded, artist, album. Without the CORS line the play command still goes through — the page just can't confirm it.
